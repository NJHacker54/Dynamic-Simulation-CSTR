# Dynamic-Simulation-CSTR
# Dynamic CSTR Simulator in Microsoft Excel

> A dynamic process simulation of a **Continuous Stirred Tank Reactor (CSTR)** developed entirely in **Microsoft Excel**, incorporating transient material and energy balances to model reactor concentration, temperature, conversion, and heat transfer behavior under varying operating conditions.

# Project Overview

The **Continuous Stirred Tank Reactor (CSTR)** is one of the most important reactor configurations in the chemical and process industries. It is widely used in petroleum refining, pharmaceutical manufacturing, wastewater treatment, food processing, polymer production, and specialty chemicals.

This project presents a **dynamic Excel-based simulator** capable of predicting the transient behavior of a non-isothermal CSTR.

Unlike traditional steady-state calculations, this simulator continuously updates reactor concentration and temperature over time by solving the governing differential equations using numerical methods implemented directly in Microsoft Excel.

The objective of this project is to demonstrate how engineering principles can be combined with spreadsheet modeling to create an interactive process simulator without requiring specialized software such as Aspen Plus, MATLAB, or COMSOL.

# Reactor Description

A Continuous Stirred Tank Reactor is assumed to satisfy the following conditions:

- Perfect mixing
- Uniform temperature throughout the reactor
- Uniform concentration
- Constant density
- Constant reactor volume
- Single irreversible reaction
- Continuous feed and product streams
- External cooling jacket

# Mathematical Model

The simulation is based on solving coupled nonlinear differential equations.

## Material Balance

$$
V\frac{dC_A}{dt}
=
F(C_{A0}-C_A)-Vr_A
$$
where

- \(V\) = Reactor volume
- \(F\) = Volumetric flow rate
- \(C_A\) = Reactor concentration
- \(C_{A0}\) = Feed concentration
- \(r_A\) = Reaction rate

---

## Reaction Kinetics

For a first-order reaction,

\[
r_A=kC_A
\]

The temperature-dependent reaction rate constant is given by the Arrhenius equation,

\[
k=k_0
\exp
\left(
-\frac{E}{RT}
\right)
\]

where

- \(k_0\) = Frequency factor
- \(E\) = Activation energy
- \(R\) = Universal gas constant
- \(T\) = Reactor temperature

---

## Energy Balance

The transient energy balance is

\[
\rho C_pV
\frac{dT}{dt}
=
\rho C_pF(T_0-T)
+
(-\Delta H)V r_A
-
UA(T-T_c)
\]

The model simultaneously accounts for

- Convective energy transport
- Heat generated by reaction
- Heat removed through the cooling jacket

---

# Numerical Method

The governing differential equations are solved using a time-stepping numerical integration approach implemented entirely through Microsoft Excel formulas.

Each simulation step updates:

1. Reaction rate
2. Concentration
3. Temperature
4. Heat generation
5. Heat removal
6. Reactor conversion

until the specified simulation time is reached.
